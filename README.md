# メセルソンとスタールの実験ラボ

DNAがどのように複製されるのかを体験しながら確かめられる、ブラウザで使えるインタラクティブ教材です。

👉 **実験ラボを開く**: https://tyama11.github.io/meselson-stahl-lab/

## 目的

メセルソンとスタールの実験をもとに、DNA複製の3つの仮説（**保存的複製**・**半保存的複製**・**分散的複製**）を自分の手で組み立てて遠心分離にかけることで、世代ごとのバンドの位置や割合の違いを直感的に理解することを目的としています。

## できること・使い方

1. **第0世代の基準を確かめる**  
   重い窒素（¹⁵N）だけでできた元の赤いDNAを遠心分離にかけ、一番下に沈むことを確かめます。
2. **3つの仮説でDNAを複製する（第1世代・第2世代）**  
   - **保存的複製**：上から下へなぞって青い2本鎖を作る
   - **半保存的複製**：右側の鎖を隣へドラッグして開き、上から下へなぞって青い鎖を合成する
   - **分散的複製**：ハサミ線を左右になぞって切り、上から下へなぞって青い断片を埋める
3. **遠心分離機で比重のバンドを観察する**  
   スタートで回転させながらDNAが移動する様子を観察し、ストップでバンドの位置と割合を確認します。
4. **3つの仮説と実際の実験結果を比べる**  
   各仮説の結果は自動で記録され、「📊 結果の比較」から並べて比較したり、実際の実験結果を表示して考察したりできます。

## 動作環境

- インストール不要（PC・タブレット・スマートフォンのブラウザでそのまま利用できます）
